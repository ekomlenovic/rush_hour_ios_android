# Niveau joueur / XP
labels: enhancement, phase-3

Une barre de progression qui avance **à chaque partie**, même courte : sentiment de progression continue.

- [ ] XP gagnée : niveau réussi (selon difficulté et étoiles), défi du jour, missions, succès
- [ ] Courbe de niveaux (ex. `100 * n^1.5`) et titre par palier : Apprenti, Chauffeur, Pilote, Maître du trafic…
- [ ] Récompense à chaque montée de niveau (cosmétique tous les 5 niveaux, gel de streak)
- [ ] Affichage : badge sur l'accueil, barre dans le profil, animation sur l'écran de victoire
- [ ] Recalcul rétroactif de l'XP pour les joueurs existants à partir de `progress` (migration)
